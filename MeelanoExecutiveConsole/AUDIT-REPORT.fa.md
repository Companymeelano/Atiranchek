# گزارش بازبینی فنی MEELANO Executive Console

**دامنه:** بازبینی سورس WPF/XAML، مدل و منطق مالی، ViewModel، خروجی/چاپ، اسکریپت ساخت، Setup، workflow، manifest، مستندات و فایل‌های منابع. تغییرهای این گزارش بر شاخهٔ کاری فعال ثبت می‌شوند؛ build نهایی ویندوز و smoke test باید در workflow تأیید شوند.

## یافته‌های پرریسک که اصلاح شدند

| بخش | یافته | اقدام |
|---|---|---|
| startup و XAML | اتصال دوطرفه به ویژگی فقط‌خواندنی `SimulatedGap` می‌توانست هنگام بازشدن پنجره برنامه را متوقف کند. این عیب در نسخهٔ پیشین با تست نصب/اجرا آشکار شد. | اتصال OneWay صریح حفظ شده و smoke test اجرا را شرط انتشار می‌کند. |
| محاسبهٔ هفت‌روزه | انتهای بازه `امروز + ۷` به‌صورت inclusive، در عمل ۸ روز را جمع می‌کرد. | بازه به امروز تا شش روز بعد محدود شد؛ آزمون مرز ۷ روز اضافه شد. |
| نمودار فروش | نمودار تراکنش‌ها را به‌عنوان روزهای مستقل نشان می‌داد و برای روز دارای چند فروش، برچسب تکراری می‌ساخت. | مدل نمودار جداگانه اضافه و فروش هر روز قبل از ترسیم تجمیع شد؛ آزمون تجمیع اضافه شد. |
| رادار نقدینگی | چک پرداختی معوق در روزهای پیش‌بینی دیده نمی‌شد، در حالی که چک دریافتی معوق به امروز منتقل می‌شد. | هر دو نوع تعهد معوق در روز صفر تجمیع می‌شوند؛ بیرون از افق ۳۰روزه حذف می‌شوند. |
| انتقال وضعیت | شمارش موارد ردشده بعد از Refresh می‌توانست به reset انتخاب WPF وابسته شود؛ منطق انتقال هم داخل ViewModel بود. | انتقال در FinanceService متمرکز، انتخاب قبل از refresh snapshot و تعداد موفق/ردشده مستقل محاسبه می‌شود. |

| بسته‌های سورس | ZIP قدیمی شامل `bin/obj` و سورس عقب‌افتاده بود. | هر دو ZIP از سورس جاری بازسازی و خروجی build حذف شد؛ archive AI-Ready بریف ساخت را نیز نگه می‌دارد. |
| کیفیت خودکار | آزمون مستقل برای دامنه وجود نداشت. | Core از WPF جدا و ۱۲ specification بدون بستهٔ ثالث برای محاسبات، وضعیت، جست‌وجو، تجمیع نمودار و CSV افزوده شد. |

## پوشش تغییرات
- **Core:** تاریخ و بازه، وضعیت‌ها، cash flow، سناریو، تاریخ وزنی، دادهٔ demo، قالب‌بندی فارسی و CSV.
- **UI:** bindingها و handlerهای XAML، انتخاب و فیلتر، grid خالی، نشانگر فوکوس صفحه‌کلید، وضعیت پنجره، خروجی و چاپ.
- **تحویل:** .NET solution، script PowerShell، Inno Setup، GitHub Actions build/test/smoke/release و مسیر عیب‌یابی.
- **مستندات:** ادعاهای نسخه، تاریخ میلادی، محدودیت دادهٔ دمو و فرمان‌های ساخت/آزمون.

## مواردی که عمداً رفع‌شده محسوب نمی‌شوند
1. برنامه هنوز **دمو** است؛ اتصال به SQL Server آتیران یا schema آن در سورس وجود ندارد. برای نسخهٔ عملیاتی قرارداد داده و مجوز دسترسی باید از مالک سامانه دریافت شود.
2. دادهٔ واقعی پایدار، کاربر/نقش، audit مالی، تراکنش، backup/restore و همگام‌سازی چندکاربره پیاده نشده‌اند.
3. ریسک، ماندهٔ آغازین و فروش نمونه‌ای/ساختگی‌اند؛ خروجی‌ها گزارش رسمی حسابداری یا پیش‌بینی بانکی نیستند.
4. نصب‌کننده code-signed نیست؛ برای توزیع سازمانی گواهی امضای معتبر و سیاست به‌روزرسانی لازم است.
5. محیط فعلی عامل، Windows/WPF را محلی اجرا نمی‌کند. build ویندوزی و smoke test CI باید موفق شوند؛ چاپگر، SmartScreen، DPIهای متعدد و سخت‌افزار واقعی نیازمند آزمون دستی‌اند.

## پیشنهاد ارتقا به محصول حرفه‌ای
قرارداد read-only و least-privilege برای SQL → احراز هویت و نقش‌ها → ممیزی تغییرات با علت/کاربر/زمان → کنترل ماندهٔ آغازین و reconciliation → اعلان سررسید و backup/restore → آزمون پذیرش روی Windows و امضای دیجیتال. هیچ مرحلهٔ write مالی پیش از تأیید مالک فرایند و آزمون rollback فعال نشود.
