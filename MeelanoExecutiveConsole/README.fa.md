# میلانو | کنسول مدیران

بازطراحی لوکس و فارسیِ راست‌به‌چپ برای پایش نمونه‌ای فروش، چک‌های دریافتی/پرداختی و جریان نقدی. پنجره در شروع تمام‌صفحه و بدون قاب باز می‌شود؛ با `F11` یا `Esc` می‌توان بین حالت تمام‌صفحه و پنجره‌ای جابه‌جا شد. رابط برای DPIهای مختلف ویندوز و پنجره‌های قابل تغییر اندازه تنظیم شده است.

> **مهم:** این برنامه دمو است. همهٔ طرف‌حساب‌ها، چک‌ها، ریسک‌ها و فروش‌ها ساختگی‌اند؛ داده‌ها فقط در حافظه‌اند و با بستن برنامه حذف می‌شوند. اتصال SQL Server آتیران پیاده‌سازی یا پیکربندی نشده است. از این نسخه برای تصمیم یا عملیات واقعی مالی استفاده نکنید.

## پیش‌نیاز اجرا
- Windows 10 یا 11؛ رابط WPF فقط روی Windows اجرا می‌شود.
- برای ساخت، .NET 8 SDK یا جدیدتر.
- برای اجرای خروجی self-contained ساخته‌شده با اسکریپت پایین، نصب جداگانهٔ .NET Desktop Runtime لازم نیست.

## ساخت فایل EXE مستقل
در PowerShell، داخل پوشهٔ `MeelanoExecutiveConsole`:

```powershell
Set-ExecutionPolicy -Scope Process Bypass
.\Build-Windows.ps1
```

خروجی x64 در این مسیر ساخته می‌شود:

```text
artifacts\win-x64\MeelanoExecutiveConsole.exe
```

برای ویندوز ARM64:

```powershell
.\Build-Windows.ps1 -RuntimeIdentifier win-arm64
```

این اسکریپت Release را به‌صورت self-contained و single-file منتشر می‌کند. به‌علت محدودیت‌های WPF و معماری Windows، فایل EXE باید روی Windows با .NET SDK منتشر شود؛ کپی‌کردن فایل‌های `bin` قدیمی یا خروجی Linux جایگزین build نهایی نیست.

## Build دستی

```powershell
dotnet restore .\MeelanoExecutiveConsole.sln
dotnet build .\MeelanoExecutiveConsole.sln --configuration Debug
dotnet run --project .\MeelanoExecutiveConsole.csproj
```

## قابلیت‌های این نسخه
- داشبورد مدیریتی با شاخص‌های فروش امروز، ورودی/خروجی هفت‌روزه، خالص، هشدارها و سررسیدهای نزدیک.
- مرکز چک با جست‌وجو، فیلتر نوع/وضعیت، انتخاب چندردیفی، جمع و رأس‌گیری مبلغ، CSV فارسی UTF-8 و چاپ.
- تغییر وضعیت کنترل‌شده: وصول فقط برای چک دریافتی، پرداخت فقط برای چک پرداختی؛ تعلیق و بازگردانی محدود به وضعیت معتبر.
- نمای فروش با جمع‌های محاسبه‌شده، فروشنده/مشتری برترِ محاسبه‌شده از دادهٔ دمو و نمودار روزانه.
- رادار ۳۰روزه با نقطهٔ شروع صفر و سناریوی واقعی جابه‌جایی تاریخ چک‌های دریافتیِ انتخاب‌شده در بازهٔ ۱۴ روز زودتر تا ۳۰ روز دیرتر.
- خروجی CSV با quoting استاندارد برای ویرگول، نقل‌قول و خط جدید؛ اعداد فارسی در رابط. تاریخ‌های نمایشی Gregorian هستند و تبدیل شمسی ادعا نمی‌شود.
- پنجرهٔ تمام‌صفحه، کنترل‌های سفارشی پنجره، حداقل ابعاد مناسب، پیمایش و اعلام واضح حالت دمو.

## محدودیت‌ها
- داده‌ها در `DemoRepository` نمونه و درون‌حافظه‌ای‌اند؛ ذخیره‌سازی پایدار، احراز هویت، مجوز، ممیزی و اتصال SQL وجود ندارد.
- امتیاز ریسک نمونهٔ ثابت است و ارزیابی اعتباری محسوب نمی‌شود.
- پیش‌بینی نقدینگی فقط بر چک‌های با وضعیت «در انتظار» و ماندهٔ آغازین صفر تکیه می‌کند؛ «تعلیق‌شده»ها در پیش‌بینی منظور نمی‌شوند. این خروجی موجودی بانکی واقعی نیست.
- تغییر وضعیت تنها در اجرای فعلی برنامه باقی می‌ماند و پس از بستن حذف می‌شود.

## ساختار پروژه
`Models` مدل‌ها و قالب‌بندی؛ `Services` محاسبات و مخزن دمو؛ `ViewModels` وضعیت و فیلتر رابط؛ `Views` رابط WPF؛ `Build-Windows.ps1` ساخت فایل اجرایی مستقل Windows.
