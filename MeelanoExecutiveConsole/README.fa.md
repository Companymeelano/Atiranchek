# MEELANO | کنسول مدیران

نسخهٔ **1.0.2**؛ داشبورد مدیریتی دسکتاپ فارسی و راست‌به‌چپ با پوستهٔ تیرهٔ گرافیتی/سبزآبی و جزئیات طلایی. پنجره در شروع بیشینه باز می‌شود؛ با `F11` یا `Esc` می‌توان حالت پنجره را تغییر داد. چینش قابل تغییر اندازه است، ناحیه‌های بلند پیمایش می‌شوند و ستون‌های جدول در پنجرهٔ باریک اسکرول افقی دارند.

> **مهم — نسخهٔ نمایشی:** طرف‌حساب‌ها، چک‌ها، ریسک‌ها و فروش ساختگی‌اند؛ تغییر وضعیت فقط در حافظه می‌ماند و با بستن برنامه حذف می‌شود. اتصال SQL Server آتیران، ذخیره‌سازی پایدار، احراز هویت یا مجوزدهی در این نسخه وجود ندارد. برای تصمیم یا عملیات واقعی مالی استفاده نکنید.

## نصب و امنیت
نصب‌کنندهٔ per-user برای Windows 10 نسخهٔ 1809 (build 17763) و جدیدتر، یا Windows 11 x64 ساخته می‌شود و دسترسی Administrator نمی‌خواهد. میان‌بر Start Menu ساخته می‌شود؛ میان‌بر Desktop اختیاری است و حذف برنامه از Apps/Installed Apps در دسترس است.

نصب‌کننده و برنامه **امضای دیجیتال ندارند**؛ Windows SmartScreen ممکن است هشدار ناشر ناشناس نشان دهد. فایل را فقط از منبع مورد اعتماد دریافت کنید. بستهٔ self-contained است و به نصب جداگانهٔ .NET Desktop Runtime نیاز ندارد.

## ساخت در Windows
پیش‌نیاز: .NET 8 SDK و در صورت ساخت Setup، Inno Setup 6. از ریشهٔ مخزن:

```powershell
.\MeelanoExecutiveConsole\Build-Windows.ps1 -Installer
```

اسکریپت ابتدا مشخصات خودکار منطق Core را اجرا می‌کند، سپس نسخهٔ self-contained را می‌سازد. نسخهٔ Setup از مقدار `Version` در فایل پروژه خوانده می‌شود.

خروجی‌ها:

```text
MeelanoExecutiveConsole\artifacts\win-x64\MeelanoExecutiveConsole.exe
MeelanoExecutiveConsole\artifacts\installer\MEELANO-Executive-Console-Setup-win-x64.exe
```

برای ساخت فایل قابل‌حمل Windows ARM64 (بدون Setup در تعریف فعلی):

```powershell
.\MeelanoExecutiveConsole\Build-Windows.ps1 -RuntimeIdentifier win-arm64
```

## آزمون و اجرای دستی
آزمون‌های بدون وابستگی به بسته‌های جانبی در پروژهٔ Specs هستند و روی Windows و .NET 8 اجرا می‌شوند:

```powershell
dotnet run --project .\MeelanoExecutiveConsole.Specs\MeelanoExecutiveConsole.Specs.csproj --configuration Release
```

ساخت و اجرای برنامهٔ WPF:

```powershell
dotnet restore .\MeelanoExecutiveConsole\MeelanoExecutiveConsole.sln
dotnet build .\MeelanoExecutiveConsole\MeelanoExecutiveConsole.sln --configuration Debug
dotnet run --project .\MeelanoExecutiveConsole\MeelanoExecutiveConsole.csproj
```

WPF فقط روی Windows اجرا می‌شود؛ اجرای نسخهٔ نهایی باید با ساخت Windows و smoke test نصب‌کننده تأیید شود.

## قابلیت‌های فعلی
- داشبورد فروش امروز، مجموع ورودی/خروجی **هفت روز تقویمی شامل امروز**، هشدارها و سررسیدها.
- مرکز چک با جست‌وجوی فارسی/عربی و رقم‌های فارسی یا عربی، فیلتر نوع/وضعیت، چندانتخابی و جمع مبالغ.
- کنترل انتقال وضعیت: وصول فقط برای چک دریافتی، پرداخت فقط برای چک پرداختی؛ تعلیق/بازگردانی فقط از وضعیت معتبر.
- محاسبهٔ تاریخ وزنی برای چک‌های انتخاب‌شدهٔ در انتظار؛ گزارش چاپی جدولی و خروجی CSV با UTF-8 BOM، quoting صحیح و محافظت از سلول‌های متنی در برابر اجرای فرمول صفحه‌گسترده.
- نمای فروش با مجموع‌های محاسبه‌شده، رتبه‌بندی و نمودار تجمیعی روزانه؛ رادار ۳۰روزه که تعهدهای معوق را در روز اول نشان می‌دهد.
- سناریوی جابه‌جایی سررسید چک‌های دریافتی انتخاب‌شده از ۱۴ روز زودتر تا ۳۰ روز دیرتر؛ سناریو به پرداختی‌ها دست نمی‌زند.
- رقم‌های فارسی در رابط؛ تاریخ‌ها صریحاً میلادی‌اند و تبدیل شمسی ادعا نمی‌شود. پنجرهٔ قابل تغییر اندازه با نشانگرهای فوکوس صفحه‌کلید.

## عیب‌یابی
خطاهای اجرا در `%LOCALAPPDATA%\MEELANO\Logs\startup.log` ثبت می‌شوند. اگر فایل از ۱ مگابایت عبور کند، نسخهٔ قبلی با پسوند `.previous` نگه داشته می‌شود. هنگام خطای UI پیام فارسی نمایش داده می‌شود؛ متن گزارش را برای بررسی ارسال کنید.

## محدودیت‌ها و هشدارهای محاسباتی
- داده‌ها از `DemoRepository` می‌آیند و پایدار نیستند؛ risk score ساختگی است و ارزیابی اعتباری نیست.
- برآورد نقدینگی فقط چک‌های در انتظار را با ماندهٔ آغازین صفر جمع می‌کند؛ چک معوق در روز اول رادار نشان داده می‌شود، اما این خروجی ماندهٔ بانکی نیست.
- اتصال، schema یا query پایگاه داده آتیران پیاده‌سازی/حدس زده نشده است؛ هر اتصال عملیاتی نیازمند قرارداد داده، دسترسی کمینه، هویت، ممیزی، ذخیره‌سازی و آزمون تأییدشده است.

## ساختار پروژه
- `MeelanoExecutiveConsole` — رابط WPF، انتشار و نصب‌کننده.
- `MeelanoExecutiveConsole.Core` — مدل‌ها، محاسبات، وضعیت‌ها، قالب‌بندی و CSV؛ مستقل از WPF.
- `MeelanoExecutiveConsole.Specs` — آزمون‌های خوداجرا برای مرزهای محاسبات، وضعیت، جست‌وجو و CSV.
- `.github/workflows/build-windows.yml` — build، اجرای Specs، نصب/اجرای smoke test و انتشار نسخهٔ عمومی فقط پس از موفقیت تست‌ها.
