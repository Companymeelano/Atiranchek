# میلانو اندروید · نسخهٔ آزمایشی ۰.۱.۰

برنامهٔ مستقل Android 7.0 (API 24) و جدیدتر برای پردازندهٔ arm64 و شبیه‌ساز x86_64 است. رابط موبایل از منطق مالی مشترک نسخهٔ ویندوز استفاده می‌کند: نمای کلی، فیلتر چک، فروش، رادار، تحلیل خزانه، هشدار سررسید، گزارش چک طرف حساب و مقایسهٔ آزمایشی CSV بانک و دفتر. داده‌های آغازین نمونه و ساختگی‌اند. اطلاعات بارگذاری‌شده فقط در حافظه نگهداری می‌شوند؛ با بستن برنامه از بین می‌روند و همگام‌سازی زنده انجام نمی‌شود.

## اتصال مستقیم آزمایشی SQL

فقط در یک **شبکهٔ آزمایشی ایزوله** با حساب SQL Login محدود و دادهٔ آزمایشی از اتصال استفاده کنید. همانند نسخهٔ آزمایشی ویندوز، ترافیک رمزگذاری می‌شود اما با `TrustServerCertificate=true` اعتبار گواهی و هویت سرور بررسی نمی‌شود؛ حملهٔ مرد میانی می‌تواند رمز و داده را افشا کند. آن را در اینترنت یا محیط عملیاتی به کار نبرید و پورت SQL را عمومی نکنید. Windows Authentication و جست‌وجوی شبکه در نسخهٔ موبایل ارائه نشده است. میزبان، پورت، نام دیتابیس و نام کاربری و رمز در هر بار اجرا وارد می‌شوند و در فایل تنظیمات ذخیره نمی‌شوند.

بارگذاری فقط‌خواندنی است و هیچ دستوری برای تغییر اطلاعات ارسال نمی‌شود؛ حساب نیز باید فقط مجوز لازم برای خواندن و metadata داشته باشد. دو View قراردادی `MEELANO_Checks` و `MEELANO_Sales` مطابق [قرارداد نسخهٔ ویندوز](../MeelanoExecutiveConsole/README.fa.md) لازم است. نام جدول/ستون دستی نگاشت نمی‌شود و دادهٔ نامعتبر به جای حدس رد می‌شود. سقف موبایل ۲۵٬۰۰۰ ردیف برای هر نما است؛ دادهٔ بیشتر بریده نمی‌شود و کل بارگذاری رد می‌شود. تا تکمیل اعتبارسنجی، snapshot قبلی حفظ می‌شود. پشتیبانی TLS و اتصال باید روی سرور و دستگاه واقعی خودتان آزمون شود.

## محدودیت‌های گزارش و امکانات

رادار فقط چک‌های در انتظار و ماندهٔ آغازین صفر را محاسبه می‌کند؛ موجودی بانکی واقعی نیست. گزارش طرف حساب فقط بر پایهٔ چک‌هاست و اشخاص هم‌نام ممکن است ادغام شوند؛ ماندهٔ دفتر نیست. مقایسهٔ CSV پیشنهادی است و ثبت سند یا تأیید رسمی نیست؛ دو فایل UTF-8 با سرستون `id,account,date,reference,direction,amount`، تاریخ میلادی و مبلغ تومان با قرارداد نسخهٔ ویندوز لازم‌اند. هشدار فقط داخل برنامه است؛ اعلان پس‌زمینه، ثبت سند، ویرایش وضعیت، چاپ، صادرات CSV و همگام‌سازی خودکار در این نسخه وجود ندارد. گزارش‌ها برای تصمیم مالی باید با مسئول مالی و دادهٔ واقعی کنترل شوند.

فونت [Vazirmatn](https://github.com/rastikerdar/vazirmatn) تحت SIL OFL 1.1 استفاده شده است؛ متن مجوز در `Resources/Fonts/OFL.txt` همراه برنامه قرار دارد.

## ساخت و نصب

با .NET 10 SDK و workload `maui-android`:

```sh
dotnet workload install maui-android
dotnet publish MeelanoMobile/MeelanoMobile.csproj -c Release -p:AndroidKeyStore=false
```

APK آزمایشی با کلید debug ماشین ساخت امضا می‌شود، نه کلید انتشار اختصاصی. دستگاه ممکن است دربارهٔ نصب از منبع ناشناس هشدار دهد و با هر تغییر کلید CI، نصب روی نسخهٔ قبلی نیاز به حذف آن داشته باشد. APK برای انتشار عمومی یا فروشگاه مناسب نیست؛ نسخهٔ عملیاتی نیازمند کلید امضای پایدار، آزمون امنیتی و سرویس ارتباطی امن است.
